# AWS Migration and Hybrid Architecture

## 1. 6R Migration Strategies
- Rehost (lift-and-shift)
- Replatform
- Refactor/Re-architect
- Repurchase
- Retain
- Retire

## 2. Migration Services
- AWS Application Migration Service (MGN)
- AWS Database Migration Service (DMS)
- AWS DataSync
- AWS Transfer Family
- Snow Family for large offline transfer

## 3. Discovery and Planning
- Migration Hub
- Application Discovery Service
- Total Cost of Ownership analysis
- Dependency mapping

## 4. Hybrid Connectivity
- Site-to-Site VPN
- Direct Connect
- Transit Gateway
- Outposts (AWS infrastructure on-prem)

## 5. Migration Phases
1. Assess
2. Mobilize
3. Migrate and modernize

## 6. Cutover Best Practices
- Pilot migration first
- Run parallel validation
- Define rollback plan
- Perform performance and security testing before production cutover
