# LeetCode and Codeforces Practice

This folder is divided by difficulty:

- `easy/` - start here and complete all easy problems first.
- `medium/` - move here after the easy folder is comfortable.
- `hard/` - advanced problems after medium practice.
- `streamapis/` - Java Stream API coding questions from easy to hard.
- `sql/` - SQL interview questions and full query answers from easy to hard.
- `real_life_examples/` - Java demos that connect classic algorithms and data structures (BFS, DFS, hashing, graphs, sorting, searching, DP, pattern matching, queues, stacks) to real-world use cases.

Each problem note follows this format:

1. Platform and problem name
2. Problem statement in simple words
3. Constraints
4. Examples
5. Java brute-force solution
6. Java best approach
7. Complexity analysis

## Recommended Order

Finish problems in this order:

1. Arrays and hashing
2. Two pointers
3. Strings
4. Stack and queue
5. Binary search
6. Linked list
7. Trees
8. Graph basics
9. Dynamic programming basics
