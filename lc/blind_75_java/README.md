# Blind 75 in Java

This folder is a self-contained study path for the classic Blind 75 set. The
problems are ordered by topic so that related patterns are learned together.

Every problem note contains:

1. A complete problem statement
2. Constraints, examples, and edge cases
3. A brute-force Java solution first
4. An optimized Java solution second
5. A step-by-step explanation and complexity comparison

## How to Study

Read the brute-force section before the optimized section. Try to identify the
repeated work or unnecessary storage in the first solution. Then implement the
optimized solution without looking at it, test the listed edge cases, and write
down the invariant that makes the optimization correct.
