2. `02-data-types-collections.md` - Lists, tuples, dictionaries, sets, type conversion
3. `03-control-flow.md` - Conditionals, loops, comprehensions
4. `04-functions.md` - Functions, lambda, decorators, closures
5. `05-oop.md` - Object-oriented programming, classes, inheritance
6. `06-exception-handling.md` - Try-except, custom exceptions, context managers
7. `07-file-handling.md` - File I/O, CSV, JSON, binary files
8. `08-modules-packages.md` - Importing, packages, pip, virtual environments
9. `09-advanced-topics.md` - Generators, decorators, itertools, functools
10. `10-interview-questions-bank.md` - 60+ interview questions with answers
