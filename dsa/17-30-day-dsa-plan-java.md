# 30-Day DSA Plan (Easy to Hard, Java)

Goal: Build interview-ready DSA skills in 30 days with structured progression.

Rule:
- Daily: 2 concepts + 2 coding problems + 1 revision
- Time: 2 to 3 hours/day

---

## Week 1 (Day 1-7): Strong Basics (Easy)

### Day 1
- Arrays: traversal, min/max, reverse
- Problems: Largest element, reverse array

### Day 2
- Strings: palindrome, frequency map
- Problems: Palindrome check, anagram

### Day 3
- Sorting basics: bubble, selection, insertion
- Problems: sort array, check sorted array

### Day 4
- Binary search
- Problems: first/last occurrence, square root integer

### Day 5
- HashMap and HashSet
- Problems: two sum, frequency count

### Day 6
- Stack and Queue
- Problems: valid parentheses, next greater element (basic)

### Day 7
- Revision + mock test (8 easy problems)

---

## Week 2 (Day 8-14): Core Patterns (Easy to Medium)

### Day 8
- Linked List basics
- Problems: reverse linked list, middle of linked list

### Day 9
- Two pointers
- Problems: pair sum sorted, move zeros

### Day 10
- Sliding window
- Problems: max sum subarray size k, longest unique substring

### Day 11
- Prefix sum and difference array
- Problems: range sum queries, subarray sum equals k

### Day 12
- Recursion basics
- Problems: factorial, power, fibonacci recursion

### Day 13
- Backtracking
- Problems: subsets, permutations

### Day 14
- Revision + medium test

---

## Week 3 (Day 15-21): Trees, Graph, Heap, Greedy (Medium)

### Day 15
- Binary tree traversals
- Problems: inorder/preorder/postorder

### Day 16
- BST basics
- Problems: search BST, LCA in BST

### Day 17
- Heap/PriorityQueue
- Problems: kth largest, top k frequent

### Day 18
- Graph BFS/DFS
- Problems: BFS traversal, number of islands

### Day 19
- Topological sort + Union Find basics
- Problems: course schedule, cycle detection

### Day 20
- Greedy algorithms
- Problems: activity selection, jump game

### Day 21
- Revision + mixed medium mock

---

## Week 4 (Day 22-30): Advanced (Medium to Hard)

### Day 22
- Dynamic programming intro
- Problems: climbing stairs, house robber

### Day 23
- DP on sequences
- Problems: LCS, LIS

### Day 24
- DP on knapsack style
- Problems: 0/1 knapsack, coin change

### Day 25
- Graph shortest path
- Problems: Dijkstra, Bellman-Ford

### Day 26
- String algorithms
- Problems: KMP, Rabin-Karp

### Day 27
- Bit manipulation
- Problems: single number, count bits, max XOR pair

### Day 28
- Range query structures
- Problems: Fenwick tree, segment tree (range sum)

### Day 29
- Hard problems day
- Problems: trapping rain water, median of two sorted arrays, word ladder

### Day 30
- Final revision + full mock interview round

---

## Daily Checklist

1. Solve without looking at solution first.
2. Write brute force and optimized version.
3. Say time and space complexity.
4. Re-solve wrong problems next day.
