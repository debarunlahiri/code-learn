# DSA in Java (Easy Notes)

This folder contains beginner-friendly DSA notes with simple Java code.

## Files

1. `01-data-structures-easy-java.md`
   - Arrays, ArrayList, LinkedList, Stack, Queue, HashMap, Tree basics
2. `02-algorithms-easy-java.md`
   - Searching, sorting, BFS, DFS
3. `03-more-data-structures-easy-java.md`
   - HashSet, PriorityQueue, Deque, Trie, DSU
4. `04-more-algorithms-easy-java.md`
   - Insertion sort, selection sort, recursion, sliding window, two pointers, DP
5. `05-practice-questions-easy-java.md`
   - 10 easy DSA questions with simple Java answers
6. `06-practice-questions-medium-java.md`
   - medium-level patterns (sliding window, heap, DFS grid, BST LCA)
7. `07-practice-questions-hard-java.md`
   - hard-level patterns (binary search partition, advanced graph/heap)
8. `08-algorithms-recursion-backtracking-java.md`
   - recursion, subsets, permutations, N-Queens
9. `09-algorithms-greedy-java.md`
   - interval scheduling, jump game, fractional knapsack
10. `10-algorithms-graph-java.md`
   - topological sort, Dijkstra, Kruskal, Bellman-Ford
11. `11-algorithms-dp-java.md`
   - climbing stairs, house robber, knapsack, LCS, coin change, LIS
12. `12-algorithms-string-java.md`
   - KMP, Rabin-Karp, Z-function, Manacher
13. `13-algorithms-bit-manipulation-java.md`
   - set bits, XOR tricks, bitmask subsets, max XOR pair
14. `14-algorithms-number-theory-java.md`
   - gcd/lcm, sieve, mod pow, modular inverse, nCr mod p
15. `15-algorithms-range-query-java.md`
   - prefix sums, difference array, Fenwick tree, segment tree
16. `16-company-wise-dsa-sheet-java.md`
   - company-targeted problem sets (TCS/Infosys/Wipro/Cognizant/HCL/Product)
17. `17-30-day-dsa-plan-java.md`
   - structured day-by-day easy-to-hard preparation plan
18. `18-algorithms-advanced-trees-java.md`
   - tree hard patterns: diameter, max path sum, serialize/deserialize, LCA
19. `19-algorithms-advanced-graph-java.md`
   - graph hard patterns: Floyd-Warshall, SCC, bridges, 0-1 BFS
20. `20-algorithms-advanced-dp-java.md`
   - DP hard patterns: edit distance, MCM, partition, tree-DP
21. `21-java-dsa-interview-templates.md`
   - quick reusable templates for interview coding rounds

2. Rewrite each solution once without looking.
3. Move to next level only when current level feels natural.
