Goal: Comprehensive guide to prepare for technical interviews.

### Resume and Portfolio
- [ ] Update resume with latest projects
- [ ] Prepare portfolio/GitHub links
- [ ] Practice elevator pitch (2-minute intro)
- [ ] Prepare questions for the interviewer

### Technical Setup
- [ ] Test internet connection
- [ ] Prepare coding environment (IDE/compiler)
- [ ] Test video/audio setup

- [ ] Get good sleep (8+ hours)

## 🎯 Core Concepts Checklist

### Data Structures (Must Know)
- [ ] **Arrays**: Operations, time complexity, edge cases
- [ ] **Strings**: Manipulation, pattern matching, algorithms
- [ ] **Linked Lists**: Singly, doubly, circular, operations
- [ ] **Stacks**: LIFO, applications, implementations
- [ ] **Queues**: FIFO, circular queues, priority queues
- [ ] **Hash Tables**: Hashing, collisions, time complexity
- [ ] **Trees**: Binary trees, BST, traversals, operations
- [ ] **Heaps**: Min/max heap, priority queue, heapify
- [ ] **Graphs**: Representations, traversals, algorithms
- [ ] **Tries**: Prefix trees, applications

### Algorithms (Must Know)
- [ ] **Searching**: Linear, binary, hash-based
- [ ] **Sorting**: Bubble, selection, insertion, merge, quick
- [ ] **Recursion**: Base cases, stack overflow, backtracking
- [ ] **Dynamic Programming**: Memoization, tabulation, patterns
- [ ] **Greedy Algorithms**: When to use, proofs
- [ ] **Graph Algorithms**: BFS, DFS, shortest paths, MST
- [ ] **Tree Algorithms**: Traversals, LCA, serialization
- [ ] **String Algorithms**: KMP, Rabin-Karp, pattern matching
- [ ] **Bit Manipulation**: Operations, tricks, applications
- [ ] **Mathematical**: GCD, LCM, primes, modular arithmetic

### Problem Patterns (Must Recognize)
- [ ] **Two Pointers**: Sorted arrays, merging, pairs
- [ ] **Sliding Window**: Subarrays, substrings, fixed/variable
- [ ] **Fast/Slow Pointers**: Cycles, middle element
- [ ] **Merge Intervals**: Overlapping, scheduling
- [ ] **In-place Reversal**: Arrays, linked lists
- [ ] **Monotonic Stack**: Next greater, histogram
- [ ] **Topological Sort**: Dependencies, DAGs
- [ ] **Binary Search Variants**: Rotated arrays, peak element
- [ ] **Backtracking**: Subsets, permutations, N-Queens
- [ ] **Union-Find**: Connected components, MST

## 🏢 Company-Specific Preparation

### WITCH Companies (Wipro, Infosys, TCS, Cognizant, HCL)
- [ ] **Focus**: Fundamentals, clean code, basic DS/Algo
- [ ] **Common Topics**: Arrays, strings, linked lists, sorting
- [ ] **Difficulty**: Easy to Medium
- [ ] **Practice**: Basic implementations, edge cases
- [ ] **Time Management**: 45-60 minutes per problem

#### Preparation Checklist:
- [ ] Array operations (search, sort, rotate)
- [ ] String manipulation (palindrome, anagram)
- [ ] Linked list basics (reverse, cycle detection)
- [ ] Tree traversals (inorder, preorder, level order)
- [ ] Basic sorting algorithms
- [ ] Simple DP problems (fibonacci, climbing stairs)
- [ ] Hash map applications
- [ ] Stack/Queue implementations

### FAANG Companies (Facebook/Meta, Amazon, Apple, Netflix, Google)
- [ ] **Focus**: Optimization, scalability, advanced algorithms
- [ ] **Common Topics**: Advanced DS, complex algorithms, system design
- [ ] **Difficulty**: Medium to Hard
- [ ] **Practice**: Optimal solutions, time/space analysis
- [ ] **Time Management**: 30-45 minutes per problem

#### Preparation Checklist:
- [ ] Advanced array techniques (range queries, optimization)
- [ ] Complex string algorithms (KMP, advanced patterns)
- [ ] Advanced tree algorithms (LCA, balanced trees, serialization)
- [ ] Graph algorithms (shortest paths, network flow, advanced)
- [ ] Complex DP (multi-dimensional, optimization)
- [ ] Advanced data structures (BIT, Segment Tree, Trie)
- [ ] Bit manipulation tricks
- [ ] Mathematical algorithms
- [ ] System design fundamentals
- [ ] Optimization techniques

## 🎪 Practice Strategy

### Daily Routine
- [ ] **Morning (30 min)**: Review concepts
- [ ] **Afternoon (1 hour)**: Solve 2-3 problems
- [ ] **Evening (30 min)**: Review solutions
- [ ] **Before sleep**: Read interview experiences

### Weekly Schedule
- [ ] **Monday**: Arrays and Strings
- [ ] **Tuesday**: Linked Lists and Stacks
- [ ] **Wednesday**: Trees and Graphs
- [ ] **Thursday**: Dynamic Programming
- [ ] **Friday**: Greedy and Math
- [ ] **Saturday**: Mock interviews
- [ ] **Sunday**: Review and rest

### Problem Difficulty Progression
1. **Week 1-2**: Easy problems (LeetCode Easy)
2. **Week 3-4**: Medium problems (LeetCode Medium)
3. **Week 5-6**: Hard problems (LeetCode Hard)
4. **Week 7-8**: Company-specific problems
5. **Week 9-10**: Mock interviews and refinement

## 📱 Mock Interview Checklist

### Before Mock Interview
- [ ] Choose realistic problem difficulty
- [ ] Set timer (45-60 minutes)
- [ ] Have whiteboard/paper ready
- [ ] Record session (if possible)
- [ ] Practice explaining thought process

### During Mock Interview
- [ ] **Clarify requirements**: Ask questions
- [ ] **Discuss approach**: Explain before coding
- [ ] **Consider edge cases**: Think about boundaries
- [ ] **Write clean code**: Use meaningful names
- [ ] **Test solution**: Walk through examples
- [ ] **Analyze complexity**: Time and space

### After Mock Interview
- [ ] Review recording (if available)
- [ ] Identify areas for improvement
- [ ] Practice weak areas
- [ ] Get feedback from others
- [ ] Update preparation checklist
