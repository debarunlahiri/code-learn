- Strings and frequency maps
- Sorting + searching
- Basic recursion
- Stack/queue basics

### Must-practice problems
1. Two Sum
2. Move Zeros
3. Valid Parentheses
4. First Non-Repeating Character

6. Merge Two Sorted Arrays
